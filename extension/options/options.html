All ML inference (AASIST deepfake detection, Whisper transcription, LLM scam-pattern analysis, voiceprint matching) runs on the server you configure — the extension only captures tab audio and renders the server's scores. If a model is unavailable, the extension shows "unavailable", never a fake safe score.
